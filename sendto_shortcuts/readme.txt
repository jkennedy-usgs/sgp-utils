These shortcuts can be added to the right-click "Send to" menu in Windows Explorer.
They have to be added on a per-user basis.

To do so:
1) Type Win-r (windows key + "r") to open the run menu
2) Type shell:sendto to open the sendto folder
3) Drag and drop (or copy and paste) the shortcuts from C:\sgp-utils\sendto_shortcuts 
to the sendto folder
